# Installing MySQL

MySQL is a popular open-source relational database management system used for web and data-driven applications.  
Here's a quick guide to install **MySQL** and **MySQL Workbench** — a graphical tool for managing databases.

---

## Step 1: Download MySQL Installer
1. Visit the official MySQL website: [https://dev.mysql.com/downloads/installer/](https://dev.mysql.com/downloads/installer/)
2. Choose **MySQL Installer for Windows** (prefer the *full version* if you have a stable internet connection).

---

## Step 2: Run the Installer
```bash
# Launch the installer
# Choose installation type
Select "Developer Default"   # Installs MySQL Server, Workbench, and other tools
Click Next                   # Let the installer check for requirements
```

---

## Step 3: Install and Configure MySQL Server
```bash
# Select MySQL Server and Workbench (if not already preselected)
Click Next → Execute         # Begin installation
```

**Configure MySQL Server:**
```bash
Choose: Standalone MySQL Server
Set Root Password: <your_password>  # Remember this for login
Add New User: (optional)
```

---

## Step 4: Finish Installation
```bash
# Complete configuration
# Launch MySQL Workbench from Start Menu
# Connect using root credentials
```

---

## 🎉 You're Done!
Now **MySQL** and **Workbench** are ready to use.  
You can start:
- Creating databases  
- Running SQL queries  
- Building and managing your data-driven applications
